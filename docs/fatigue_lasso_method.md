# Load Channel Reduction for Block Cycle Fatigue Testing via Influence Tensor and Group LASSO

> **Document purpose**: Technical reference — method derivation, algorithmic design, validation evidence.
> **Last updated**: 2026-08-03

---

## 1. Problem Statement

### 1.1 Engineering Context

In automotive durability development, the fatigue damage of a structural component (e.g., a cradle, subframe, or weld zone) is driven by a large set of measured or simulated road loads. A typical multi-body simulation or road load data acquisition (RLDA) campaign produces **dense multi-channel load histories** — commonly 64 to 128 independent force/moment channels recorded at multiple attachment points — capturing the full dynamic response of the vehicle over a representative drive mission.

To validate the component on a physical test rig, engineers develop a **block cycle test**: a finite sequence of load blocks applied by a small number of hydraulic actuators. The fundamental constraint is that a typical multi-axis test rig supports only **4 to 8 independent channels**, far fewer than the 64–128 channels in the original load data.

This creates the **channel reduction problem**:

> Given a dense-channel target load event (e.g., 96 channels) that produces a known fatigue damage distribution across the component, identify a **sparse subset of load channels** (e.g., 6 channels) and their corresponding amplitudes such that the predicted fatigue damage distribution best reproduces the target — including the correct ranking of the most critical elements.

The difficulty is not merely computational. Two fundamentally different load subsets may produce similar total strain energy but completely different spatial damage distributions, inverting which elements are the most fatigue-critical. A method that matches total stress well but inverts the damage ranking provides no structural validation value.

### 1.2 The Role of Influence Tensors

For linear elastic FE models, the stress tensor at any element is a linear function of the applied loads. This is encoded in the **influence (transfer) matrix H**:

$$\boldsymbol{\sigma} = \mathbf{H}\,\mathbf{f}$$

where:
- **H** ∈ ℝ^(m × n): each column is the stress tensor produced by one unit-amplitude load channel (computed once by FE analysis with SPC unit loads)
- **f** ∈ ℝ^n: the vector of load channel amplitudes to be identified
- **σ** ∈ ℝ^m: the resulting stress tensor (m = n_elem × 6 components per element)

Physically, each column of H is an **SPC (Single Point Constraint) unit load response** — the stress field produced by applying 1 N in one direction at one attachment point while all other loads are zero. By superposition, any combination of loads maps to Hf.

The channel reduction problem thus becomes: find a **sparse** f such that Hf best reproduces the target stress tensor generated by the original dense load event.

### 1.3 Why Stress Matching Alone Is Insufficient

The first instinct is to minimize `‖Hf − σ_target‖`. However, fatigue damage is driven by the **stress range** Δσ = σ_max − σ_min across load cycles, not by the absolute stress level. A target load event has both a maximum stress state σ_max and a minimum stress state σ_min.

Matching only σ_min (or σ_max) inverts the damage ranking:

| Method | Element 10058616 (true rank 1) | Element 10032399 | Range error |
|--------|-------------------------------|-----------------|-------------|
| Single-subcase LASSO (match σ_min only) | Rank 108 | Rank 1 (false positive) | ~27% |
| **Fatigue LASSO V2** (match Δσ + ranking constraint) | Target: Rank 1 | — | Reported per run |

Root cause: a solution that fits σ_min accurately may produce an entirely wrong Δσ pattern, because Δσ depends on the joint fit of both extremes. Element ranking by fatigue damage is therefore a fundamentally different objective from element ranking by stress magnitude.

**This paper addresses the joint problem**: select sparse load channels **and** identify amplitudes that reproduce the correct fatigue damage ranking, using the stress range Δσ as the primary fitting target.

## 2. Mathematical Formulation

### 2.1 Notation

| Symbol | Dimension | Meaning |
|--------|-----------|---------|
| H | m × n | Influence matrix; m = n_elem × 6, n = 3 × n_groups |
| σ_max, σ_min | m | Target MAX/MIN stress tensors from the target load event |
| Δσ | m | Stress range = σ_max − σ_min (primary fatigue driver) |
| σ_mean | m | Mean stress = (σ_max + σ_min)/2 (controls R-ratio) |
| f_range | n | Range force vector = f_max − f_min (block cycle amplitudes) |
| f_mean | n | Mean force vector = (f_max + f_min)/2 (block cycle offsets) |
| g = 1..G | — | Force group index; G = n / 3 (one FX/FY/FZ triplet per attachment point) |
| A ⊆ {1..G} | — | Active group set (selected channels) |
| K | int | User-specified maximum number of active groups (rig budget) |
| W | m × m | Diagonal element weight matrix |

### 2.2 Group Structure of the Load Channels

The SPC unit-load library is organized by **force groups**: each attachment point contributes three load channels (FX, FY, FZ). In a block cycle test, it is physically natural to either include or exclude all three directions at a given attachment point — a partial triplet is impractical to apply on a test rig.

This group structure is the motivation for **Group LASSO** rather than elementwise LASSO: the sparsity penalty acts on groups of three columns simultaneously, producing solutions where entire attachment-point triplets are either fully active or fully zero.

Group index g occupies columns `[3g, 3g+1, 3g+2]` in H (columns sorted by subcase ID). This alignment is preserved throughout the algorithm.

### 2.3 Phase 1 — Stress Range Matching via Group LASSO

The primary objective is to recover **f_range** by matching Δσ with group sparsity constrained to at most K active groups:

$$\mathbf{f}^*_{\text{range}} = \arg\min_{\mathbf{f}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g=1}^{G} \|\mathbf{f}_g\|_2$$

where **f**_g = (F_X^g, F_Y^g, F_Z^g) is the force triplet for attachment point g, and λ controls group sparsity.

**Active group set**: A = {g : ‖**f**_g‖₂ > ε}.  
**Group count control**: λ is selected via binary search on log(λ) to enforce |A| ≤ K.  
**Relaxed OLS**: after selecting A, refit without penalty to remove LASSO shrinkage bias:

$$\hat{\mathbf{f}}_{\text{range}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2$$

### 2.4 Phase 0 — Influence-Guided Mandatory Channel Pre-Selection

Before running the Group LASSO, guarantee that the active set A contains channels that can physically excite the critical (most damage-sensitive) elements. Define the **influence score** of attachment point g on element e:

$$\text{influence}(e, g) = \|\mathbf{H}_{e,g}\|_F$$

where **H**_{e,g} ∈ ℝ^(6×3) is the H submatrix for element e and force group g.

For each critical element, the top-K_mand groups by influence score are **pre-designated as mandatory**. Phase 1 then uses Block Coordinate Descent (BCD) that respects the mandatory set:

$$\min_{\mathbf{f}_{\text{mand}}, \mathbf{f}_{\text{free}}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}_{\text{mand}}\mathbf{f}_{\text{mand}} + \mathbf{H}_{\text{free}}\mathbf{f}_{\text{free}} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g \notin \text{mand}} \|\mathbf{f}_g\|_2$$

BCD alternates:
1. **f_mand** ← Weighted OLS on H_mand, holding H_free f_free fixed
2. **f_free** ← Group LASSO on H_free with budget K_free = K − |mand|, holding H_mand f_mand fixed

Final joint OLS on all selected columns removes shrinkage bias.

**Rationale**: if the Group LASSO freely optimises the global error, it may select attachment points that produce accurate stress at the majority of elements while contributing near-zero stress at the critical element — leaving no force basis to excite it regardless of amplitude. Phase 0 prevents this by guaranteeing coverage of the critical elements.

### 2.5 Phase 2 — Mean Stress Identification

After Phase 1 locks the active set A, recover **f_mean** on the same support:

$$\mathbf{f}^*_{\text{mean}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \boldsymbol{\sigma}_{\text{mean}})\|_2^2$$

This is weighted Ridge (α = 1×10⁻⁸ for numerical stability) on the active columns. Restricting to the same support as Phase 1 enforces physical consistency: the block cycle MAX and MIN loads are applied at the same attachment points, with different magnitudes.

### 2.6 Block Cycle Load Recovery

$$\mathbf{f}_{\text{max}} = \mathbf{f}_{\text{mean}} + \frac{\mathbf{f}_{\text{range}}}{2}, \qquad \mathbf{f}_{\text{min}} = \mathbf{f}_{\text{mean}} - \frac{\mathbf{f}_{\text{range}}}{2}$$

These two force vectors define one complete block cycle: apply f_max to the test rig (MAX load block), then apply f_min (MIN load block). Repeat for the specified number of cycles.

### 2.7 Phase 3 — Damage Ranking Refinement (Fixed-Support IRLS)

If the initial Phase 1 solution does not achieve the target damage ranking, Phase 3 runs an Iterative Re-weighted Least Squares (IRLS) loop on the **fixed support** from Phase 1.

**Critical invariant**: the active set A is frozen after Phase 1. Phase 3 only adjusts force amplitudes within A. Re-running the group selection inside the IRLS loop causes catastrophic error explosion (see §4.1).

```
For iteration k = 1..max_iter:
    f_range ← WeightedOLS(H[:, A], Δσ, W)          # fixed support, no LASSO
    s_e     ← VonMises_range(H @ f_range) per element
    ranks   ← argsort(-s_e), 1-indexed

    For each critical element c_p with actual rank r_p:
        gap = max(r_p − p, 0)
        if gap > 0:
            weight[c_p] ← min(weight[c_p] × γ^gap, 1×10⁸)

    if all r_p == p: break
    if no improvement for 3 consecutive iterations: break
```

Two modes are available (see §4.3.6):
- **Residual mode** (default): IRLS weight boosting drives the OLS to fit the critical element's Δσ more tightly
- **Ranking mode**: SLSQP constrained optimisation with explicit margin constraints on the damage ordering

### 2.8 Damage Proxy

The per-element ranking signal is the **Von Mises equivalent stress range**:

$$s_e = \max\!\left(
  \sqrt{\Delta\sigma_{XX}^2 + \Delta\sigma_{YY}^2 - \Delta\sigma_{XX}\Delta\sigma_{YY} + 3\Delta\sigma_{XY}^2}
\right)_{\text{face 1, face 2}}$$

This proxy is monotonically related to Palmgren-Miner fatigue damage for an S-N curve with exponent m = 3–5, making it a reliable ranking signal without requiring full rainflow counting at each IRLS iteration.

## 3. Algorithm Summary

```
INPUT:
  σ_max, σ_min   — target event MAX/MIN stress tensors  (m,)
  H              — SPC influence matrix                  (m × n)
  critical_elems — elements whose damage rank must match list
  target_ranking — desired rank order for critical elems list
  K              — max active force groups (rig channel budget) int
  K_mand         — mandatory groups per critical element  int (default 2)

PHASE 0 — Influence analysis
  For each critical element e:
    influence[e, g] = ||H[e_rows, g_cols]||_F  for all g
    mandatory_groups ← union of top-K_mand per critical element

PHASE 1 — Group selection (runs ONCE, result is locked)
  Compute Δσ = σ_max − σ_min
  If mandatory_groups non-empty:
    solve_bcd(H, Δσ, W, mandatory_groups, K) → active_mask_fixed
  Else:
    binary_search(λ) → group_lasso(H, Δσ, W, K) → active_mask_fixed

PHASE 3 — Amplitude refinement (IRLS, optional)
  For k = 1..max_iter:
    f_range ← weighted_ols(H[:, active_mask_fixed], Δσ, W)  # FIXED SUPPORT
    ranks   ← von_mises_ranking(H @ f_range)
    Update W for under-ranked critical elements (w ← w × γ^gap)

PHASE 2 — Mean load identification (uses Phase 3 best state)
  σ_mean = (σ_max + σ_min) / 2
  f_mean ← weighted_ols(H[:, active_mask_fixed], σ_mean, W_init)

RECOVERY
  f_max = f_mean + f_range/2    ← block cycle MAX load amplitudes
  f_min = f_mean − f_range/2    ← block cycle MIN load amplitudes

OUTPUT:
  f_max, f_min               — block cycle load vectors (K active channels)
  group_influence_*.csv      — Phase 0 influence scores (transparency)
  f_range_*.csv, f_mean_*.csv
  ranking_check_*.csv        — predicted damage rank vs. target rank
  run_log_*.txt              — full metadata, H shape, α, errors, IRLS history
```

## 4. Diagnostic Evidence and Design Decisions

### 4.1 V1 Failure Mode: IRLS with Re-Running Group Selection

| Metric | V1 Value | Commentary |
|--------|----------|-----------|
| Active groups | 3 / 15 | Too few; selection ignored critical element coverage |
| Δσ relative error | 34.77% | Moderate |
| Element 10058616 achieved rank | **108** | Target: rank 1 |
| YY1 predicted / target (10058616) | 13 Pa / 222 Pa | 94% underestimate |
| IRLS error at iteration 1 | **139.4%** | Catastrophic — 4× worse than initial |
| best_iteration | 0 | IRLS never improved on Phase 1 result |

**Root cause 1 — Wrong group selection**: The 3 auto-selected groups minimised global Δσ error but contributed near-zero stress to element 10058616. No IRLS weight boost can compensate for zero basis coverage.

**Root cause 2 — IRLS group instability**: Each IRLS iteration re-ran the binary-search Group LASSO with updated weights. The updated weight distribution caused a completely different set of 3 groups to be selected each iteration, destroying the previous fit and preventing convergence.

**Root cause 3 — CLI parsing**: On Windows PowerShell, `\` is not a line continuation character. The command `--max-active-groups 6 \` was parsed incorrectly. Use `` ` `` for PowerShell line continuation.

### 4.2 V2 Design Decisions

| Decision | Rationale |
|----------|-----------|
| Phase 0 mandatory groups | Guarantees the force basis spans the critical element's stress space |
| BCD instead of joint Group LASSO | Mandatory groups have zero penalty; BCD converges to the global optimum of the composite objective |
| Lock active set after Phase 1 | Eliminates IRLS group instability; OLS on fixed support cannot select a different channel set |
| Phase 3 uses OLS not LASSO | OLS preserves the amplifying effect of weight boosts in the normal equations |
| Phase 2 uses same active set | Physical consistency: block cycle MAX/MIN loads share the same attachment points |

### 4.3 Ranking Enforcement Mechanism and Failure Analysis (2026-05-28)

#### 4.3.1 Three Layers of Ranking Enforcement

**Phase 0 — Coverage guarantee**

$$\text{influence}(e, g) = \|\mathbf{H}_{e,g}\|_F$$

Top-K groups per critical element are mandated active. Necessary but not sufficient for ranking correctness.

**Phase 1 (BCD) — Group selection with guaranteed coverage**

- `f_mand` ← WeightedOLS(H_mand, Δσ − H_free f_free)
- `f_free` ← GroupLasso(H_free, Δσ − H_mand f_mand, ≤ free_budget groups)

The mandatory groups are always in the final active set, regardless of the global error landscape.

**Phase 3 — Amplitude refinement on fixed support**

*Residual mode*: IRLS weight boosting —
$$w_e \leftarrow \min\!\left(w_e \cdot \gamma^{\mathrm{gap}},\ 10^8\right), \quad \mathrm{gap} = r_e - p_e$$

*Ranking mode*: SLSQP direct constraint enforcement (see §4.3.6).

#### 4.3.3 Root Cause: Basis Insufficiency

Under any linear combination of the active channels A, the Von Mises stress range at element e is:

$$s_e(\mathbf{f}_A) = \mathrm{VM\_range}\!\left(\mathbf{H}_{e,A}\,\mathbf{f}_A\right)$$

For element 10058616 to rank #1, there must exist some f_A such that:
$$s_{10058616}(\mathbf{f}_A) > s_e(\mathbf{f}_A) \quad \text{for all } e \neq 10058616$$

If the column structure of H[:, A] systematically excites other elements more than element 10058616 **for every direction f_A**, this condition is impossible — no weight boosting can fix it.

**Physical interpretation**: element 10058616 ranks #1 in the target event likely due to distributed inertia body-load components that produce a specific spatial stress pattern. Point-force SPC channels produce a fundamentally different spatial distribution, where other structural elements (e.g., 10032399 near a stiffness discontinuity) are more excited by any linear combination of attachment-point forces.

#### 4.3.6 Ranking Mode: Direct Constraint Optimisation

**Motivation**: in residual mode, a rank-gap of 40 at iteration 0 drives the weight to 2^40 × 10 ≈ 10¹³, immediately hitting the cap (10⁸) in one step. The capped OLS forces the critical element's stress upward but simultaneously amplifies competitor elements even more — worsening the rank.

**Ranking mode formulation**: given the fixed active support A from Phase 1, solve:

$$\min_{\mathbf{f}_A} \quad \frac{1}{2m}\|\mathbf{H}_A\mathbf{f}_A - \Delta\boldsymbol{\sigma}\|_2^2$$

$$\text{subject to:} \quad s_{c_p}(\mathbf{f}_A) - s_b(\mathbf{f}_A) \geq \delta, \quad \forall b \in \text{blockers}(c_p)$$

where **blockers**($c_p$) = elements currently ranked above desired rank $p$ for critical element $c_p$, and δ = `--ranking-margin` (Pa, default 0).

The constraint Jacobian uses precomputed H submatrices (6×|A| per element), so SLSQP evaluations involve only small matrix-vector products regardless of the full 109,524-row H.

| Aspect | Residual mode (default) | Ranking mode |
|--------|------------------------|--------------|
| Objective | Fit critical element Δσ via weight | Fit Δσ globally; ranking via constraints |
| Weight saturation | Yes — 1-step saturation possible | No weights |
| Error at convergence | May explode to 98.6% | Stays near Phase 1 level |
| Best use case | Basis spans element well; stress accuracy needed | Ranking is primary goal |

### 5.5 Stress Tensor Comparison Tool

The comparison tool validates the channel reduction result: does applying the sparse K-channel block cycle loads (f_max / f_min) in a full FE run reproduce the original dense-channel target stress field? The LASSO pipeline solves this in matrix space, but the FE solver is the ground truth — this tool bridges the two.

#### Why two separate runs are needed

The script compares **one subcase at a time**. Block cycle validation requires running it twice:

| Run | `--target-subcase` | `--result` | What it verifies |
|-----|--------------------|-----------|-----------------|
| MAX | original MAX subcase (e.g. `1000001`) | FE result with f_max applied | Does f_max reproduce the peak stress state σ_max? |
| MIN | original MIN subcase (e.g. `1000002`) | FE result with f_min applied | Does f_min reproduce the trough stress state σ_min? |

Both runs are mandatory. A good MAX match with a poor MIN match still produces the wrong Δσ = σ_max − σ_min pattern, inverting the fatigue damage ranking. The script has no built-in dual-subcase mode; Δσ comparison must be done manually from the two reports.

#### Subcase selection logic (from the code)

```python
# lines 456–457 in compare_stress_tensors.py
target_subcase = args.target_subcase if args.target_subcase is not None else args.subcase
result_subcase = args.result_subcase if args.result_subcase is not None else args.subcase
```

`--subcase N` sets both to N simultaneously. `--target-subcase` and `--result-subcase` override each side independently. Use the independent flags whenever the two files use different subcase numbering — which is the normal case for Cradle HAZ (target uses `1000001`/`1000002`, FE result uses `1`, `2`, …).

#### Component order and VON handling

The script fixes the internal component order as:

```python
COMPONENT_ORDER = ["VON", "XX1", "YY1", "XY1", "XX2", "YY2", "XY2"]
```

VON occupies index 0. The 6 tensor components (XX1 … XY2) occupy indices 1–6. Metrics are computed separately for each index using stride-7 slicing (`target[i::7]`). **VON is never optimised by the pipeline** — it is a scalar derived by the FE solver from the 6 components. The tool reports it as a cross-check: if the 6-component fit is accurate, VON should also agree; if it does not, there is a component-sign or face-assignment error.

The 2×3 scatter grid (Fig 1b) plots indices 1–6 only (skipping VON). Layout:

```
Row 0 (top face):    XX1  |  YY1  |  XY1
Row 1 (bottom face): XX2  |  YY2  |  XY2
```

Asymmetry between rows indicates bending-dominated loading (top face in tension, bottom in compression, or vice versa). A symmetric result (rows look identical) indicates membrane-dominated loading.

#### Metrics and why each was chosen

```python
# _compute_metrics() — lines 121–132
diff  = result - target
mae   = mean(|diff|)
rmse  = sqrt(mean(diff²))
max_ae= max(|diff|)
r2    = 1 - SS_res / SS_tot
pr, _ = pearsonr(target, result)
mask  = abs(target) >= 1e-6          # exclude near-zero target values
mape  = mean(|diff[mask] / target[mask]|) × 100
```

| Metric | Why this metric for fatigue validation |
|--------|----------------------------------------|
| **MAE** | Mean absolute error in MPa — the simplest absolute accuracy check, directly interpretable against yield stress and S-N thresholds |
| **RMSE** | Penalises large outliers more than MAE; critical because fatigue damage scales as Δσ^m (m = 3–5), so a 2× stress error at the rank-1 element causes 8–32× damage error |
| **Max AE** | Single worst-case element error; if this element is the rank-1 critical element, the run must be rejected regardless of good mean metrics |
| **R²** | Spatial pattern preservation — near-1 means the pipeline correctly identifies which regions carry high vs. low stress; the primary condition for correct damage ranking |
| **Pearson r** | Linear correlation; can be near-1 even when a systematic scale offset exists, which R² would penalise. Together they distinguish a well-correlated-but-biased result from a pattern mismatch |
| **MAPE** | Relative error in %; the `|target| ≥ 1e-6` filter excludes near-zero target values. Without this filter, shear components (XY) and elements near the neutral axis would produce MAPE → ∞ from trivially small absolute errors |

**Damage amplification**: a 10% stress error propagates to ~30–60% damage error (m = 3–5). Engineering acceptance typically requires per-component MAPE ≤ 10–15% at the critical elements and global R² ≥ 0.95.

The "global" row in the report concatenates all 7 components × all elements into one flat vector before computing metrics — a single-number summary useful for automated QA but less interpretable than per-component values.

#### Density-coloured scatter plots (Fig 1)

With 18,254 elements × 7 components = 127,778 points per comparison, a plain scatter plot is a solid blob. The script uses kernel density estimation (KDE) to colour each point by local density:

```python
# _density_scatter() — lines 210–221
if len(x) > 4000:
    idx = rng.choice(len(x), 4000, replace=False)   # subsample for KDE speed
    kde = gaussian_kde(xy[:, idx])
kde applied to ALL points; sorted by density so dense (yellow) points plot on top
```

Dense (bright yellow) regions = many elements at that stress level; sparse (dark blue) = outlier elements. Points are plotted in ascending density order so high-density clusters are not buried under outliers. The 1:1 reference line shows perfect agreement; scatter above/below reveals systematic over- or under-prediction at specific stress levels.

#### Bland-Altman agreement plots (Fig 2)

```python
# plot_von_bland_altman() — lines 308–334
mean_val = (target + result) / 2
diff     = result - target
bias     = mean(diff)
loa_hi   = bias + 1.96 × std(diff)
loa_lo   = bias - 1.96 × std(diff)
```

The x-axis is the mean of target and result; the y-axis is their difference. This separates two failure modes that scatter plots hide:

- **Constant bias** (horizontal shift of all points away from zero): indicates a systematic error — e.g., wrong unit scaling between the target event and the FE result, or a wrong load normalisation factor in H
- **Proportional bias** (funnel shape — spread increases with stress magnitude): indicates that the pipeline fits low-stress elements well but increasingly under- or over-predicts at high-stress elements, which are exactly the fatigue-critical ones

The ±1.96σ limits of agreement (LoA) define the 95% interval under the normality assumption. For block cycle test acceptance, bias should be near zero and LoA should be within the fatigue-relevant stress amplitude of the critical elements.

#### ECDF of absolute relative error (Fig 4)

```python
# plot_ecdf() — lines 402–433
rel_err = |result - target| / |target| × 100  (elements where |target| ≥ 1e-6 only)
x-axis: log scale
reference lines at 5 % and 10 %
legend shows fraction of elements with error ≤ 10 %
```

The ECDF shows the full distribution, not just a summary statistic. Log x-scale spreads the well-matched bulk (< 5%) and exposes the error tail simultaneously. The key reading is:

- What fraction of elements are within 10% error? (shown in legend)
- Where is the 95th percentile error? (read from the curve at ECDF = 0.95)

A good channel reduction shows a steep ECDF that reaches ~90% of elements by 10% error. A poor result has a long flat tail extending to 100–1000%. The pipeline's objective is ranking, not uniform accuracy — so a long tail is expected, but the tail elements must not include the critical rank-1/rank-2 elements.

#### Component bar chart (Fig 3)

MAE and RMSE are plotted side-by-side per component. VON bar is highlighted with a green outline to distinguish it from the 6 optimised components. Components with disproportionately high RMSE relative to MAE indicate outlier elements with very large pointwise errors — follow up with the scatter grid to identify which stress regime they fall in.

#### Recommended additional metric (not yet implemented)

For dual-subcase comparisons (MAX + MIN both available), the most direct fatigue fidelity metric is the **Spearman rank correlation of per-element stress range**:

```python
delta_sigma_VM = sigma_VM_max - sigma_VM_min          # per element
rho_s = spearmanr(delta_sigma_VM_result, delta_sigma_VM_target).statistic
```

`ρ_s` near 1 means the pipeline preserves the damage ranking across all elements — the primary objective of the channel reduction. This should be added to `compare_stress_tensors.py` when a `--target-max-subcase` / `--target-min-subcase` dual-subcase mode is implemented.

## 6. Theoretical Properties

### 6.1 Convexity

The Phase 1 Group LASSO objective is jointly convex in f for any fixed W. BCD on a jointly-convex objective converges to the global minimum. The Phase 3 fixed-support OLS is also convex. The IRLS outer loop (Phase 3) is a heuristic and is not guaranteed to find a global ranking optimum, but the fixed-support constraint prevents the divergence that characterised V1.

### 6.2 Physical Interpretability

- **Sparse group structure**: each non-zero group represents one physical attachment point with FX/FY/FZ amplitudes — directly specifiable as a test rig channel
- **Mandatory groups**: grounded in the physical principle that if group g has near-zero influence on the critical element, no finite amplitude can produce stress at it; the influence score makes the selection transparent
- **Shared active set for MAX/MIN**: enforces that the same physical channels are used for both the MAX and MIN load blocks in the test

### 6.3 Limitations

1. **Basis completeness**: if the target stress state lies outside the column span of H (e.g., because it is dominated by body-load inertia effects not representable by point forces), the channel reduction has irreducible error. Phase 0 feasibility analysis quantifies this lower bound.

2. **IRLS non-convergence**: Phase 3 is a heuristic. For some configurations, no amplitude update on the fixed support achieves the target ranking. The algorithm reports `satisfied_count / total_critical` honestly.

3. **Damage proxy vs. full rainflow**: the Von Mises range proxy ranks elements correctly for proportional, single-cycle loading but may diverge from Palmgren-Miner damage under complex multiaxial histories with variable amplitude.

4. **Linearity assumption**: H is computed from linear elastic FE analysis. Geometric nonlinearity, contact, and material plasticity are not captured; the method applies to the linear elastic fatigue regime.

## 7. Validation Checklist

Before accepting a run result for block cycle test specification:

- [ ] `stress_group_influence_*.csv` shows non-trivial scores (> 0) for the critical element at the selected mandatory groups
- [ ] Run log shows `mandatory_groups_selected` is non-empty when `--auto-mandatory-top-k > 0`
- [ ] IRLS error history is monotonically stable (no iteration exceeds 2× the initial error)
- [ ] `stress_ranking_check_*.csv` shows target element ranks within 10 of desired (even if not exact)
- [ ] `relative_error_range` (Δσ fit) is below ~30%; values above ~50% indicate the SPC basis cannot span the target event stress state
- [ ] f_max and f_min applied in a full FE run reproduce the damage ranking reported by the pipeline (cross-validation)
- [ ] Spearman rank correlation ρ_s > 0.95 across all elements (when dual-subcase comparison is available)

## 8. Future Work

1. **Multi-event channel reduction**: extend to multiple road-load events (one (σ_max, σ_min) pair each), solving a joint Group LASSO to find one sparse channel set that represents all events simultaneously — directly producing a multi-block duty cycle.

2. **Basis enrichment**: augment H with modal superposition or residual stress modes to improve coverage for elements dominated by body-load inertia effects that point-force SPC channels cannot span.

3. **Direct damage integration**: replace the Von Mises range proxy with a differentiable approximation of Palmgren-Miner damage (including rainflow cycle counting), enabling gradient-based optimisation in Phase 3.

4. **Uncertainty quantification**: propagate SPC measurement uncertainty from physical rig calibration to confidence bounds on f_range and the damage ranking.

5. **Comparison with mission synthesis**: benchmark against standard mission synthesis approaches (e.g., equivalent fatigue damage frequency-domain methods) in terms of channel count, damage ranking fidelity, and computational cost.
