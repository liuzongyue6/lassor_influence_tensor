# Sparse Load Identification for Fatigue-Critical Stress Ranking via Influence Tensor and Group LASSO (least absolute shrinkage and selection operator)

> **Scope**: The running example uses an inertia-relief (IR) event as the target, but the method applies to any dense-load target stress tensor (e.g., a road-load event synthesised from 96 channels). "IR" in section headings is shorthand for the specific Cradle HAZ case, not a method constraint.

> **Document purpose**: Technical reference.
> **Last updated**: 2026-05-27

---

## 1. Problem Statement

### 1.1 Engineering Context

In automotive durability analysis, the **target stress tensor σ_target** is generated by a large set of discrete loads (e.g., 96 load channels for inertia-relief (IR) events). The objective is to identify a **sparse subset of discrete loads** (user-specified quantity, e.g., 6 load groups) such that the predicted stress tensor Hf best reproduces σ_target — with the additional requirement that the predicted fatigue damage ranking of critical elements matches the known target ranking.


The objective is to identify a sparse set of **load groups** **f** (user-specified count K, e.g. K = 6) drawn from a candidate load library (the SPC unit-load basis), such that **H f** best reproduces **σ_target** in a fatigue-damage sense — with the additional requirement that the predicted **fatigue damage ranking** of critical elements matches the known target ranking.

**Why this matters**: Fatigue simulation is computationally expensive. If we can represent the IR event as a short list of equivalent SPC load channels, we can run fatigue sweeps (duty-cycle multiplier, geometry variants) using only those channels, reducing simulation cost by an order of magnitude.

### 1.2 Why Single-Subcase Matching Fails

The naive approach — minimising `||H f − σ_target||` for a single (e.g., MIN) subcase of the target load event — inverts the damage ranking:

| Method | Element 10058616 (true rank 1) | Element 10032399 | Range error |
|--------|-------------------------------|-----------------|-------------|
| Single-subcase LASSO | Rank 108 | Rank 1 (false positive) | ~27% |
| **Fatigue LASSO V2** | Target: Rank 1 | — | Reported per run |

Root cause: fatigue damage scales with **stress range** Δσ = σ_max − σ_min, not absolute stress. A solution that fits σ_min well may produce a completely wrong Δσ pattern, inverting which elements see the largest excitation cycles.

## 2. Mathematical Formulation

### 2.1 Notation

| Symbol | Dimension | Meaning |
|--------|-----------|---------|
| H | m × n | Influence matrix; m = n_elem × 6, n = 3 × n_groups |
| σ_max, σ_min | m | Target MAX/MIN stress tensors (from target MAX/MIN subcases) |
| Δσ | m | Stress range = σ_max − σ_min (primary fatigue driver) |
| σ_mean | m | Mean stress = (σ_max + σ_min)/2 (R-ratio) |
| f_range | n | Range force vector = f_max − f_min |
| f_mean | n | Mean force vector = (f_max + f_min)/2 |
| g = 1..G | — | Force group index; G = n / 3 |
| A ⊆ {1..G} | — | Active group set |
| W | m × m | Diagonal element weight matrix |

### 2.2 Phase 1 — Stress Range Matching (Group LASSO)

Primary objective: recover **f_range** by matching Δσ with group sparsity.

$$
\mathbf{f}^*_{\text{range}} = \arg\min_{\mathbf{f}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g=1}^{G} \|\mathbf{f}_g\|_2
$$

where **f**_g = (F_X^g, F_Y^g, F_Z^g) is the FX/FY/FZ triplet for application point g, and λ controls group sparsity.

**Active group set**: A = {g : ‖**f**_g‖₂ > ε}.  
**Group count control**: λ is selected via binary search to enforce |A| ≤ K_max (user-specified).  
**Relaxed OLS**: after selecting A, refit without penalty to remove shrinkage bias:

$$
\hat{\mathbf{f}}_{\text{range}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2
$$

### 2.3 Phase 0 — Influence-Guided Mandatory Group Pre-Selection

Before Phase 1, guarantee that the active set A **contains groups that can physically excite the critical element**:

$$
\text{influence}(e, g) = \|\mathbf{H}_{e,g}\|_F
$$

where **H**_{e,g} ∈ ℝ^(6×3) is the H submatrix for element e and group g.

For each critical element, the top-K groups by influence score are **pre-designated as mandatory**. Phase 1 then uses Block Coordinate Descent (BCD):

$$
\min_{\mathbf{f}_{\text{mand}}, \mathbf{f}_{\text{free}}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}_{\text{mand}}\mathbf{f}_{\text{mand}} + \mathbf{H}_{\text{free}}\mathbf{f}_{\text{free}} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g \notin \text{mand}} \|\mathbf{f}_g\|_2
$$

BCD alternates:
1. **f_mand** ← Weighted OLS on H_mand, fixing H_free f_free contribution
2. **f_free** ← Group LASSO on H_free with budget K_free = K_max − |mand|, fixing H_mand f_mand contribution

Final joint OLS on all selected columns removes shrinkage.

**Why BCD is sound**: The objective is convex in (f_mand, f_free) jointly. BCD converges to the global optimum. Mandatory groups have no LASSO penalty — they are guaranteed active regardless of global error distribution.

### 2.4 Phase 2 — Mean Stress Matching ROLS (Restricted Ordinary Least Squares)

After Phase 1 locks the active set A, recover **f_mean** independently:

$$
\mathbf{f}^*_{\text{mean}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \boldsymbol{\sigma}_{\text{mean}})\|_2^2
$$

This is plain weighted Ridge (α = 1×10⁻⁸ for numerical stability) on the active columns.

**Physical rationale**: Mean stress shifts the R-ratio but does not change the fatigue range. Restricting to the same support A as Phase 1 ensures physical consistency — f_max and f_min share the same force application points.

### 2.5 Recovery

$$
\mathbf{f}_{\text{max}} = \mathbf{f}_{\text{mean}} + \frac{\mathbf{f}_{\text{range}}}{2}, \qquad \mathbf{f}_{\text{min}} = \mathbf{f}_{\text{mean}} - \frac{\mathbf{f}_{\text{range}}}{2}
$$

### 2.6 Phase 3 — IRLS Ranking Refinement (Fixed-Support)

If the user specifies a target ranking [c₁, c₂, ..., c_K] (c_p must achieve global rank p), Phase 3 runs an IRLS weight-boosting loop **on the fixed support from Phase 1**.

**Critical design principle**: the active set A is frozen after Phase 1. Phase 3 only adjusts force magnitudes.

```
For iteration k = 1..max_iter:
    f_range ← WeightedOLS(H[:, A], delta_sigma, weights)   # fixed support, no LASSO
    s_e     ← VonMises_range(H @ f_range) per element
    ranks   ← argsort(-s_e), 1-indexed

    For each critical element c_p with actual rank r_p:
        gap = max(r_p − p, 0)
        if gap > 0:
            weight[c_p] ← min(weight[c_p] × γ^gap, 1×10⁸)

    if all r_p == p:  break
    if no improvement for 3 consecutive iterations:  break
```

**Why fixed support is essential**: If the IRLS loop re-ran the group LASSO binary search each iteration. As weights for element 10058616 grew, the binary search selected a different group set — one that no longer fit the other elements — and the global error jumped from 34.8% to 139.4%. By fixing A, the weight update directly amplifies the influence of element 10058616's rows in the OLS system, causing larger predicted stress at that element without destabilising the rest of the fit.

### 2.7 Damage Proxy

The ranking signal is the **per-element Von Mises equivalent stress range**:

$$
s_e = \max\!\left(
  \sqrt{\Delta\sigma_{XX}^2 + \Delta\sigma_{YY}^2 - \Delta\sigma_{XX}\Delta\sigma_{YY} + 3\Delta\sigma_{XY}^2}
\right)_{\text{face 1, face 2}}
$$

This proxy is monotonically related to the Palmgren-Miner fatigue damage for a uniaxial S-N curve with exponent m = 3..5, making it a reliable ranking signal without requiring full rainflow counting.

## 3. Algorithm Summary

```
INPUT:
  σ_max, σ_min   — IR MAX/MIN stress tensors  (m,)
  H              — SPC influence matrix        (m × n)
  critical_elems — elements to emphasise       list
  target_ranking — desired rank order          list
  K_max          — max active force groups     int
  K_mand_top     — mandatory groups per elem   int (default 2)

PHASE 0 — Influence analysis
  For each critical element e:
    influence[e, g] = ||H[e_rows, g_cols]||_F  for all g
    mandatory_groups ← union of top-K_mand_top per element

PHASE 1 — Group selection (runs ONCE)
  If mandatory_groups non-empty:
    solve_bcd(H, Δσ, W, mandatory_groups, K_max)
  Else:
    binary_search_lambda → group_lasso(H, Δσ, W, K_max)
  Lock: active_mask_fixed ← groups selected by Phase 1

PHASE 3 — Magnitude refinement (IRLS, optional)
  For k = 1..max_iter:
    f_range ← weighted_ols(H[:, active_mask_fixed], Δσ, W)  # FIXED SUPPORT
    ranks   ← von_mises_ranking(H @ f_range)
    Update W for under-ranked critical elements (w ← w × γ^gap)

PHASE 2 — Mean stress (after Phase 3 best state)
  f_mean ← weighted_ols(H[:, active_mask_fixed], σ_mean, W_init)

OUTPUT:
  f_max = f_mean + f_range/2
  f_min = f_mean − f_range/2
  ranking_check.csv   — element-level damage proxy and ranks
  group_influence.csv — Phase 0 influence scores (transparency)
```

**Root cause 1 — Wrong group selection**: The 3 auto-selected groups minimised global Δσ error but had near-zero influence on element 10058616. No IRLS weight boost can overcome zero basis coverage.

**Root cause 2 — IRLS instability**: Each IRLS iteration re-ran the binary-search group LASSO with updated weights. The new weight distribution caused a completely different set of 3 groups to be selected, destroying the previous fit.

**Root cause 3 — CLI parsing**: On Windows PowerShell, `\` at end of line is not a line-continuation character. The command `--max-active-groups 6 \` was parsed as `--max-active-groups 3` (the trailing `\` was consumed as part of the next token). Use `` ` `` for PowerShell line continuation.

### 4.2 V2 Design Decisions

| Decision | Rationale |
|----------|-----------|
| Phase 0 mandatory groups | Guarantees that the force basis spans the critical element's stress space |
| BCD instead of joint LASSO | Mandatory groups have zero penalty; BCD converges to the global optimum of the composite objective |
| Fix active set after Phase 1 | Eliminates IRLS group instability; OLS on fixed support cannot select a different group set |
| Phase 3 uses OLS not LASSO | OLS preserves the influence of weight amplification directly in the normal equations |
| Phase 2 uses same active set | Physical consistency: f_max and f_min share application points |
| Per-element independent weights | Avoids cross-contamination: boosting c_1 doesn't over-penalise c_2's residual |

### 4.3 — 2026-05-28: Ranking Enforcement Mechanism, Failure Modes, and Interventions

#### 4.3.1 How Phase 0→1→3 Enforces Element Damage Ranking

The algorithm has three layers of ranking enforcement, each with a distinct role:

**Phase 0 — Influence-guided mandatory group selection**  
Before any optimisation, Phase 0 computes the Frobenius norm of H submatrices for each critical element and each force group:

$$\text{influence}(e, g) = \|\mathbf{H}_{e,g}\|_F$$

The top-K groups per critical element are **mandated** as permanently active. This guarantees the force basis spans the critical element's stress space — a necessary (but not sufficient) condition for the ranking constraint to be achievable.

**Phase 1 (BCD) — Group selection with guaranteed coverage**  
Phase 1 runs once to fix `active_mask_fixed`. With mandatory groups, BCD alternates:
- `f_mand` ← WeightedOLS(H_mand, Δσ − H_free f_free)
- `f_free` ← GroupLasso(H_free, Δσ − H_mand f_mand, ≤ free_budget groups)

The mandatory groups are always in the final active set, regardless of global error distribution.

**Phase 3 — Magnitude refinement on fixed support**  
Two modes are available (see §4.3.6):

*Residual mode* (`--irls-mode residual`, default): Iterative Re-weighted Least Squares boosts critical element row weights by γ^gap per iteration:
$$w_e \leftarrow \min\!\left(w_e \cdot \gamma^{\mathrm{gap}},\ 10^8\right), \quad \mathrm{gap} = r_e - p_e$$
where r_e = actual rank, p_e = desired rank. The OLS solver then places more weight on minimising the critical element's residual, driving its predicted stress higher — IF the active force groups can physically produce that stress.

*Ranking mode* (`--irls-mode ranking`): SLSQP constrained optimisation. Objective is global fit; constraints directly enforce the ranking goal (see §4.3.6).

#### 4.3.3 Root Cause: Basis Insufficiency (Linear Inseparability)

Under any linear combination of the 3 active force groups, the Von Mises stress range at element e is:

$$s_e(\mathbf{f}_A) = \mathrm{VM\_range}\!\left(\mathbf{H}_{e,A}\,\mathbf{f}_A\right)$$

where H_{e,A} ∈ ℝ^(6×|A|) is the element's row block restricted to active columns.

For element 10058616 to rank #1, there must exist f_A such that:
$$s_{10058616}(\mathbf{f}_A) > s_e(\mathbf{f}_A) \quad \text{for all } e \neq 10058616$$

If the column structure of H[:, A] excites other elements more strongly than 10058616 **for every direction f_A**, this condition is impossible — no weight boosting can overcome it.

**Evidence from the run:**
- At iter 0 (Phase 1 result, weight = 10): rank 41
- At iter 1 (weight boosted to cap 1e8): rank 112 — WORSE
- The force vector that best matches element 10058616's stress components happens to amplify other elements (ranked 1–111) even more

**Physical interpretation:** Element 10058616 ranks #1 in the ground-truth IR event likely due to the distributed inertia body-load component of that event. Point-force SPC loads produce a fundamentally different spatial stress distribution, where other structural elements (e.g., 10032399 near a stiffness discontinuity) are more excited by any linear combination of SPC channels. The SPC basis is structurally unable to replicate the IR body-load spatial pattern.

#### 4.3.6 Ranking Mode: `--irls-mode ranking`

**Motivation:** In residual mode, the IRLS weight cap (1×10⁸) causes the OLS to fit element 10058616 exactly, ignoring all other elements. The resulting force vector may amplify other elements' stresses even more, worsening the ranking. The weight saturation is fundamental — a gap of 40 at iter 0 causes the weight to jump to cap in a single step (2^40 × 10 ≈ 10^13 >> cap 10^8).

**Ranking mode formulation:** Given the fixed active support A from Phase 1, the outer loop repeatedly solves:

$$\min_{\mathbf{f}_A} \quad \mathbf{f}_A^\top \mathbf{H}_A^\top \mathbf{H}_A \mathbf{f}_A - 2(\mathbf{H}_A^\top \Delta\boldsymbol{\sigma})^\top \mathbf{f}_A$$

$$\text{subject to:} \quad s_{c_p}(\mathbf{f}_A) - s_b(\mathbf{f}_A) \geq \delta, \quad \forall b \in \text{blockers}(c_p)$$

where:
- The objective is the global stress range fit (not the critical element fit)
- **blockers**($c_p$) = elements currently ranked above desired rank $p$ for critical element $c_p$
- δ = `--ranking-margin` (Pa), default 0
- $s_e(\mathbf{f}_A)$ = Von Mises stress range proxy at element e

The constraint Jacobian uses precomputed H submatrices (6×|A| per element), so SLSQP inner evaluations involve only trivial matrix-vector products (~6×9 = 54 ops) regardless of the 109,524-row H.

**Comparison:**

| Aspect | `--irls-mode residual` (default) | `--irls-mode ranking` |
|--------|----------------------------------|----------------------|
| Objective | Match Δσ at critical element via weight | Match Δσ globally; ranking via constraints |
| Weight saturation | Yes (2^gap can hit 1e8 in 1 step) | No weights — direct margin constraints |
| Error at convergence | May explode to 98.6% | Stays near Phase 1 level (~31%) |
| When ranking improves | When basis spans element well | When feasible under the active basis |
| Best use case | Basis is adequate; need stress accuracy too | Ranking is primary goal; accept fit error stays constant |

**CLI example for ranking mode:**
```powershell
python scripts/fatigue_lasso_pipeline.py `
    --irls-mode ranking `
    --ranking-margin 0 `
    --max-active-groups 6 `
    --auto-mandatory-top-k 2 `
    --critical-elems 10058616 `
    --target-ranking 10058616 `
    --output-dir outputs/cradle_ranking_mode
```

## 6. Theoretical Properties

### 6.1 Convexity

The Phase 1 objective is convex in **f** for any fixed W. BCD on a jointly-convex objective converges to the global minimum. The Phase 3 fixed-support OLS is also convex (unconstrained least squares on active columns). IRLS itself is not guaranteed to find a global ranking optimum, but the fixed-support constraint prevents the instability that made V1 diverge.

### 6.2 Physical Interpretability

- **Sparse group structure**: each non-zero group represents one physical force application point with FX/FY/FZ components. This is interpretable as "the IR event is primarily driven by K force channels."
- **Mandatory groups**: grounded in the physical principle that if group g has near-zero influence on element e, no finite f_g can explain element e's stress. The influence score makes this selection transparent and reproducible.
- **f_max, f_min share the same application points**: a physical constraint (same loading geometry, different magnitudes), enforced exactly by the shared active set.

### 6.3 Limitations

1. **Basis completeness**: if the true IR stress state lies outside the column span of H (i.e., no sparse SPC combination can reproduce it exactly), the recovery will have irreducible error. The influence analysis (Phase 0) gives a lower bound on this: if the top-K groups all have low influence scores for the critical element, the element may be fundamentally un-representable by the SPC basis.

2. **IRLS non-convergence**: Phase 3 is a heuristic. For some configurations, no weight update on the fixed support will achieve the target ranking. The algorithm reports `satisfied_count / total_critical` honestly.

3. **Damage proxy vs. full rainflow**: the Von Mises range proxy ranks elements correctly for proportional loading and single-cycle events, but may diverge from Palmgren-Miner damage under complex multiaxial histories.

- [ ] f_max and f_min applied in a full FE run reproduce the stress tensor with the same relative error as reported (cross-validation)

## 8. Future Work / Paper Directions

1. **Basis enrichment**: augment H with residual-mode shapes or modal superposition to improve coverage for IR-dominated elements that no SPC group can excite.

2. **Multi-event generalisation**: extend to multiple road-load events (one (σ_max, σ_min) pair each), solving a joint group LASSO across events to find one sparse force set that represents all events.

3. **Direct damage integration**: replace the Von Mises range proxy with a differentiable approximation of Palmgren-Miner damage, enabling gradient-based weight updates in Phase 3.

4. **Uncertainty quantification**: propagate SPC measurement uncertainty (from physical rig tests) to bounds on f_range and the damage ranking.

5. **Comparison with modal decomposition**: benchmark against the standard approach of decomposing IR loads into orthogonal inertia-relief modes and compare sparsity, error, and ranking accuracy.
