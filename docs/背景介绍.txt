To validate the component on a physical test rig, engineers develop a **block cycle test**: a finite sequence of load blocks applied by a small number of hydraulic actuators. The fundamental constraint is that a typical multi-axis test rig supports only **4 to 8 independent channels**, far fewer than the 64–128 channels in the original load data.
This creates the **channel reduction problem**:
> Given a dense-channel target load event (e.g., 96 channels) that produces a known fatigue damage distribution across the component, identify a **sparse subset of load channels** (e.g., 6 channels) and their corresponding amplitudes such that the predicted fatigue damage distribution best reproduces the target, also including the correct ranking of the most critical elements.

# 1.求解这个stress distribution的开端：Influence Tensor和delta stress

## 1.1 从考虑Influence Tensor开始[这个influence tensor的段落需要论文支持，请查找引用相关论文]
For linear elastic FE models, the stress tensor at any element is a linear function of the applied loads. This is encoded in the **influence (transfer) matrix H**:

$$\boldsymbol{\sigma} = \mathbf{H}\,\mathbf{f}$$

where:
- **H** ∈ ℝ^(m × n): each column is the stress tensor produced by one unit-amplitude load channel (computed once by FE analysis with SPC unit loads)
- **f** ∈ ℝ^n: the vector of load channel amplitudes to be identified
- **σ** ∈ ℝ^m: the resulting stress tensor (m = n_elem × 6 components per element，XX1,XX2,YY1,YY2,XY1,XY2)

Physically, each column of H is an **SPC (Single Point Constraint) unit load response** — the stress field produced by applying 1 unit load (1N or 1kN) in one direction at one attachment point while all other loads are zero. By superposition, any combination of loads maps to Hf.

The channel reduction problem thus becomes: find a sparse f such that Hf best reproduces the target stress tensor generated by the original dense load event.

这里需要讲以下选择stress tensor的原因：HAZ在汽车行业的建模是2D shell 单元，stress tensor是XX1,XX2,YY1,YY2,XY1,XY2，根据ncode designlife对于HAZ的计算需要考虑shell单元的两个面，需要用到stress tensor



## 1.2 Matching delta stress

Fatigue damage is driven by the **stress range** Δσ = σ_max − σ_min across load cycles, not by the absolute stress level. A target load event has both a maximum stress state σ_max and a minimum stress state σ_min. 
如果仅match stress min和stress max，然后组合在一起，我们最终看到的damage效果并不好，所以本次程序选择的目标是来匹配一个delta stress 而不是两个absolute stress[请叙述一下程序是如何匹配delta stress的]

# 2. the Load Channels Group 的reduction方法

## Notation

| Symbol | Dimension | Meaning |
|--------|-----------|---------|
| H | m × n | Influence matrix; m = n_elem × 6, n = 3 × n_groups |
| σ_max, σ_min | m | Target MAX/MIN stress tensors from the target load event |
| Δσ | m | Stress range = σ_max − σ_min (primary fatigue driver) |
| σ_mean | m | Mean stress = (σ_max + σ_min)/2 (controls R-ratio) |
| f_range | n | Range force vector = f_max − f_min (block cycle amplitudes) |
| f_mean | n | Mean force vector = (f_max + f_min)/2 (block cycle offsets) |
| g = 1..G | — | Force group index; G = n / 3 (one FX/FY/FZ triplet per attachment point) |
| A ⊆ {1..G} | — | Active group set (selected channels) |
| K | int | User-specified maximum number of active groups (rig budget) |
| W | m × m | Diagonal element weight matrix |

The SPC unit-load library is organized by force groups: each attachment point contributes three load channels (FX, FY, FZ). In a block cycle test, it is physically natural to either include or exclude all three directions at a given attachment point — a partial triplet is impractical to apply on a test rig. 一个测试用的hydraulic actuator的合力可以代表一个loading point上的Fx Fy Fz

This group structure is the motivation for Group LASSO rather than elementwise LASSO: the sparsity penalty acts on groups of three columns simultaneously, producing solutions where entire attachment-point triplets are either fully active or fully zero.

Group index g occupies columns `[3g, 3g+1, 3g+2]` in H (Influence matrix; m = n_elem × 6, n = 3 × n_groups). This alignment is preserved throughout the algorithm.

## 2.1 Phase 1 — Stress Range Matching via Group LASSO

The primary objective is to recover **f_range** by matching Δσ with group sparsity constrained to at most K active groups:

$$\mathbf{f}^*_{\text{range}} = \arg\min_{\mathbf{f}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g=1}^{G} \|\mathbf{f}_g\|_2$$

[这个公式需要引用文献的支持]

where **f**_g = (F_X^g, F_Y^g, F_Z^g) is the force triplet for attachment point g, and λ controls group sparsity.

**Active group set**: A = {g : ‖**f**_g‖₂ > ε}.  
**Group count control**: λ is selected via binary search on log(λ) to enforce |A| ≤ K.  
**Relaxed OLS**: after selecting A, refit without penalty to remove LASSO shrinkage bias:

$$\hat{\mathbf{f}}_{\text{range}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \Delta\boldsymbol{\sigma})\|_2^2$$

[Active group set, Group count control, Relaxed OLS这三个东西需要再展开讲讲]

## 2.2 Phase 0 — Influence-Guided Mandatory Channel Pre-Selection

Before running the Group LASSO, guarantee that the active set A contains channels that can physically excite the critical (most damage-sensitive) elements. Define the **influence score** of loading point g on element e:

$$\text{influence}(e, g) = \|\mathbf{H}_{e,g}\|_F$$

where **H**_{e,g} ∈ ℝ^(6×3) is the H submatrix for element e and force group g.

For each critical element, the top-K_mand groups by influence score are **pre-designated as mandatory**. Phase 1 then uses Block Coordinate Descent (BCD) that respects the mandatory set:

$$\min_{\mathbf{f}_{\text{mand}}, \mathbf{f}_{\text{free}}} \;\frac{1}{2m}\|\mathbf{W}(\mathbf{H}_{\text{mand}}\mathbf{f}_{\text{mand}} + \mathbf{H}_{\text{free}}\mathbf{f}_{\text{free}} - \Delta\boldsymbol{\sigma})\|_2^2 + \lambda \sum_{g \notin \text{mand}} \|\mathbf{f}_g\|_2$$

[BCD的公式和概念需要展开讲讲，也需要论文支持]
1. **f_mand** ← Weighted OLS on H_mand, holding H_free f_free fixed
2. **f_free** ← Group LASSO on H_free with budget K_free = K − |mand|, holding H_mand f_mand fixed

Final joint OLS on all selected columns removes shrinkage bias.

**Rationale**: if the Group LASSO freely optimises the global error, it may select attachment points that produce accurate stress at the majority of elements while in the block test, engineers care the critical element. Phase 0 prevents this by guaranteeing coverage of the critical elements.
[这里的guarantee是怎么做到的，需要展开讲讲]

## 2.3 Phase 2 — Mean Stress Identification

After Phase 1 locks the active set A, recover **f_mean** on the same support:

$$\mathbf{f}^*_{\text{mean}} = \arg\min_{\mathbf{f}: \operatorname{supp}(\mathbf{f}) \subseteq A} \|\mathbf{W}(\mathbf{H}\mathbf{f} - \boldsymbol{\sigma}_{\text{mean}})\|_2^2$$

This is weighted Ridge (α = 1×10⁻⁸ for numerical stability) on the active columns. Restricting to the same support as Phase 1 enforces physical consistency: the block cycle MAX and MIN loads are applied at the same attachment points, with different magnitudes.

$$\mathbf{f}_{\text{max}} = \mathbf{f}_{\text{mean}} + \frac{\mathbf{f}_{\text{range}}}{2}, \qquad \mathbf{f}_{\text{min}} = \mathbf{f}_{\text{mean}} - \frac{\mathbf{f}_{\text{range}}}{2}$$

These two force vectors define one complete block cycle: apply f_max to the test rig (MAX load block), then apply f_min (MIN load block). Repeat for the specified number of cycles.

## 2.4 Phase 3 — Damage Ranking Refinement 

If the initial Phase 1 solution does not achieve the target damage ranking, Phase 3 runs an Iterative Re-weighted Least Squares (IRLS) loop on  Phase 1. [这里需要论文来讲支持Re-weighted Least Squares (IRLS) ]

To facilitate the stress ranking, use VonMises, which comes directly from the stress tensor simulation result.
The per-element ranking signal is the **Von Mises equivalent stress range**:

$$s_e = \max\!\left(
  \sqrt{\Delta\sigma_{XX}^2 + \Delta\sigma_{YY}^2 - \Delta\sigma_{XX}\Delta\sigma_{YY} + 3\Delta\sigma_{XY}^2}
\right)_{\text{face 1, face 2}}$$




```
For iteration k = 1..max_iter:
    f_range ← WeightedOLS(H[:, A], Δσ, W)          
    s_e     ← VonMises_range(H @ f_range) per element
    ranks   ← argsort(-s_e), 1-indexed

    For each critical element c_p with actual rank r_p:
        gap = max(r_p − p, 0)
        if gap > 0:
            weight[c_p] ← min(weight[c_p] × γ^gap, 1×10⁸)

    if all r_p == p: break
    if no improvement for 3 consecutive iterations: break
```

Two modes are available (see later section for explaination) :
- **Residual mode** : IRLS weight boosting drives the OLS to fit the critical element's Δσ more tightly
- **Ranking mode**: SLSQP constrained optimisation with explicit margin constraints on the damage ordering
[这里需要再解释一下IRLS和SLSQP分别是什么]

## 2.5 Ranking Enforcement Mechanism 

in residual mode, a rank-gap of 40 at iteration 0 drives the weight to 2^40 × 10 ≈ 10¹³, immediately hitting the cap (10⁸) in one step. The capped OLS forces the critical element's stress upward but simultaneously amplifies competitor elements even more — worsening the rank.
[这里的 rank-gap of 40，the weight to 2^40 × 10 ≈ 10¹³，hitting the cap (10⁸) ，rank gap, weight and cap这三个概念需要结合上文阐述清楚]

**Ranking mode formulation**: given the fixed active load A from Phase 1, solve:

$$\min_{\mathbf{f}_A} \quad \frac{1}{2m}\|\mathbf{H}_A\mathbf{f}_A - \Delta\boldsymbol{\sigma}\|_2^2$$

$$\text{subject to:} \quad s_{c_p}(\mathbf{f}_A) - s_b(\mathbf{f}_A) \geq \delta, \quad \forall b \in \text{blockers}(c_p)$$

where **blockers**($c_p$) = elements currently ranked above desired rank $p$ for critical element $c_p$, and δ = `--ranking-margin` 

The constraint Jacobian uses precomputed H submatrices (6×|A| per element), so SLSQP evaluations involve only small matrix-vector products regardless of the full row H.


| Aspect | Residual mode (default) | Ranking mode |
|--------|------------------------|--------------|
| Objective | Fit critical element Δσ via weight | Fit Δσ globally; ranking via constraints |
| Weight saturation | Yes — 1-step saturation possible | No weights |
| Error at convergence | allow explosion to user defined limit | Stays near Phase 1 level |
| Best use case | Basis spans element well; stress accuracy needed | Ranking is primary goal |

## 2.6 Convexity
The Phase 1 Group LASSO objective is jointly convex in f for any fixed W. BCD on a jointly-convex objective converges to the global minimum. The Phase 3 fixed-support OLS is also convex.  [这里需要论文或者支持来说明为什么他们是convex的]

# 3. Algorithm Summary

```
INPUT:
  σ_max, σ_min   — target event MAX/MIN stress tensors  (m,)
  H              — Unit load influence matrix           (m × n)
  critical_elems — elements whose damage rank must match list
  target_ranking — desired rank order for critical elems list
  K              — max active force groups (rig channel budget) int
  K_mand         — mandatory groups per critical element  int (default 2)

PHASE 0 — Influence analysis
  For each critical element e:
    influence[e, g] = ||H[e_rows, g_cols]||_F  for all g
    mandatory_groups ← union of top-K_mand per critical element

PHASE 1 — Group selection (runs ONCE, result is locked)
  Compute Δσ = σ_max − σ_min
  If mandatory_groups non-empty:
    solve_bcd(H, Δσ, W, mandatory_groups, K) → active_mask_fixed
  Else:
    binary_search(λ) → group_lasso(H, Δσ, W, K) → active_mask_fixed

PHASE 3 — Amplitude refinement (IRLS mode)
  For k = 1..max_iter:
    f_range ← weighted_ols(H[:, active_mask_fixed], Δσ, W)  
    ranks   ← von_mises_ranking(H @ f_range)
    Update W for under-ranked critical elements (w ← w × γ^gap)

PHASE 2 — Mean load identification (uses Phase 3 best state)
  σ_mean = (σ_max + σ_min) / 2
  f_mean ← weighted_ols(H[:, active_mask_fixed], σ_mean, W_init)

RECOVERY
  f_max = f_mean + f_range/2    ← block cycle MAX load amplitudes
  f_min = f_mean − f_range/2    ← block cycle MIN load amplitudes

OUTPUT:
  f_max, f_min               — block cycle load vectors (K active channels)

```

# 5. Future Work

1. **Multi-event channel reduction**: extend to multiple road-load events (one (σ_max, σ_min) pair each), solving a joint Group LASSO to find one sparse channel set that represents all events simultaneously — directly producing a multi-block duty cycle.

2. **hydraulic actuator constraints**: force output angle and range could be added as constraint

3. **Damage proxy vs. full rainflow**: the Von Mises range proxy ranks elements correctly for proportional, single-cycle loading but may diverge  under complex multiaxial histories with variable amplitude. [那么你建议有什么更好的ranking方法？]
